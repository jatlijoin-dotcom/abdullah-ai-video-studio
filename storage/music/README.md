# Music library

Drop your own **royalty-free** MP3 / WAV / OGG / M4A / FLAC files in this
folder. The backend picks the first file alphabetically, loops it to the
video length and fades it out — that becomes the background music bed.

With no files here, the backend synthesises a soft ambient pad instead
(clearly labelled a placeholder).

Never add commercial songs — baking a singer's song into a video risks a
YouTube Content ID claim.
